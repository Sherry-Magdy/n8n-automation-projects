UNDER THE HOOD

The three workflows

  • recruitment-1-intake.json · form, validation, Drive, sheet
  • recruitment-2-ai-screening.json · hourly read, score, validate, email
  • recruitment-3-error-handler.json · alerts, digest, heartbeat

Design choices

  • The AI never grades itself. A code step re-checks the score range, the label and that extracted skills appear in the CV.
  • Failures never stop the batch. A bad file sets Manual Review and the loop moves on.
  • Rows are matched by CV file ID, so two applicants with the same name cannot overwrite each other.
  • Humans decide borderline cases. Only clear scores trigger emails to candidates.

Downloads have credentials, sheet IDs and email addresses removed. Sample candidates are fictional.
